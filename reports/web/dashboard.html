📖 欄位說明 — 點擊展開
📊 總覽指標
VIX美國市場恐慌指數。<20 = 低波動（綠）；20–30 = 偏高（黃）；>30 = 極高風險（紅）
市場分數系統綜合技術指標計算的多空分數，正值偏多、負值偏空
進場候選同時符合技術訊號 + 籌碼條件的波段操作候選檔數（WAVE + 衛星觀察合計）
持倉警示現有持倉中建議考慮出場或減碼的檔數
🎯 進場候選 — 各欄說明
總分敘事分 × 0.2 + 籌碼分 × 0.2 + 技術/量能加分，最高約 200 分。強力 ≥ 140、穩健 ≥ 90
敘事分由 Gemini / Claude / Perplexity 三個 AI 獨立評估產業主題強度（AI Server、HBM、半導體…）後取共識平均分，0–100
籌碼分依外資/投信/自營商當日買賣超加總計算，0–100。資料來源：TWSE（上市）與 TPEX（上櫃）官方 API
量比當日成交量 ÷ 近期均量。≥ 1.0 = 放量（綠）；0.7–1.0 = 正常；<0.7 = 縮量（灰）
外資／投信／自營當日法人買賣超張數（正 = 買超，負 = 賣超）。原始數字來自交易所，單位為股，顯示轉換為萬／千萬／億
強力買超／分歧籌碼狀態：STRONG_POSITIVE（外資+總量均大幅買超）/ POSITIVE（整體買超）/ DIVERGENCE（外資賣但投信買，或反之）/ NEGATIVE（整體賣超）
追價風險LOW = 技術面顯示尚未過熱可試單；MEDIUM = 短線漲幅偏大需謹慎；HIGH = 不建議追高
籌碼新鮮FRESH = 籌碼資料為今日或昨日；STALE/待更新 = 資料超過 2 個交易日未更新
失效條件如果這些條件發生，代表進場訊號可能失效，應重新評估或停損出場
